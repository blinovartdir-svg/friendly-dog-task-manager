# Дружелюбный пёс

Персональный Task Manager: канбан-доска, перетаскивание задач, заметки, сроки, приоритеты, поиск и импорт/экспорт JSON.

## Запуск

Откройте `dist/index.html` в браузере. Установка зависимостей и сборка не нужны. Иллюстрации встроены в HTML, поэтому файл работает самостоятельно.

Для локального сервера из корня проекта:

```sh
python3 -m http.server 8765 --directory dist
```

Адрес: http://localhost:8765.

## Изменения

Основной файл: `dist/index.html`. Редактируйте страницу, проверяйте результат в браузере и сохраняйте изменения коммитами в GitHub. Текущая хромированная эмблема также сохранена в `dist/assets/chrome-sheltie-emblem.png`.

## Данные задач

Задачи и заметки сохраняются в localStorage конкретного браузера и адреса страницы. GitHub хранит исходный код и историю изменений сайта; пользовательские задачи автоматически в GitHub не отправляются и между устройствами не синхронизируются. Для переноса задач используйте «Экспорт» и «Импорт». Перед сменой адреса страницы экспортируйте резервную копию.
